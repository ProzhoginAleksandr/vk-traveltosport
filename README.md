# TraveltoSport

Мини-приложение ВКонтакте для бегунов: калькуляторы, брейнбустер, дневник тренировок и программа подготовки к забегу.

## Что внутри

- **Калькулятор бегуна** — темп и скорость, пульсовые зоны, раскладка по километрам, прогноз VO₂max.
- **Брейнбустер** — словарь бегуна, квиз и игры на память.
- **Дневник тренировок** — импорт GPX/TCX, программа подготовки к забегу по неделям, статистика и профиль.
- **Программа подготовки** — план от текущей формы до целевого времени: темпы, пульсовые зоны, длинные и качественные тренировки, прогноз с учётом выполнения.
- **Карточка пробежки** — изображение для истории ВК: маршрут, метрики, выбор стиля и фона.

## Стек

React 18, VKUI 7, VK Bridge, `@vkontakte/vk-mini-apps-router`, Vite 5, TypeScript, MapLibre GL JS (карта в трекере, сейчас отключён).

## Команды

```sh
npm install        # зависимости
npm start          # dev-сервер Vite (http://localhost:5173)
npm run build      # продакшен-сборка в build/
npm run lint       # ESLint без предупреждений
npm run deploy:dev # сборка и публикация в dev-окружение VK
npm run deploy:prod
npm run deploy     # оба окружения
```

Для деплоя нужен `MINI_APPS_ACCESS_TOKEN` в `.env` (файл не коммитится).

## Структура

```
src/
  panels/         экраны-панели (маршруты в routes.ts)
  components/     общие компоненты: фон, таббар, карта, карточки
  components/racePlan/  экран и онбординг программы подготовки
  utils/          чистая логика: план, треки, реклама, шаринг, форматтеры
  styles/         токены дизайна и глобальные стили (Oswald, тёмная тема)
  config/         фича-флаги
```

## Данные

Сервера у приложения нет: треки, план и настройки хранятся в `localStorage` на устройстве. Очистка кэша приложения удаляет их; в разделе «Данные и конфиденциальность» есть резервная копия и полное удаление.

## Сборка и версии

Идентификатор сборки — хеш основного бандла (`index-*.js`). Он виден в заголовке вкладки и в профиле в строке «сборка …», по нему удобно проверять, какая версия открыта.
