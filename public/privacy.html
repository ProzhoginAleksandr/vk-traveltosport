Политика конфиденциальности TraveltoSport

Редакция от 15 ноября 2026 года

Кто обрабатывает данные

Мини-приложение TraveltoSport (VK Mini App, id 54647551) развивает автор проекта Александр Прожогин. Связаться можно через профиль ВКонтакте.

Какие данные использует приложение

  • имя, фамилия, фото профиля и идентификатор пользователя ВКонтакте;
  • параметры пробежек: дата, дистанция, время, темп, точки GPS-маршрута;
  • данные программы подготовки: дистанция, дата старта, цель, отметки о тренировках;
  • игровая статистика, настройки приложения и счётчики показов рекламы.

Приложение не запрашивает доступ к контактам, сообщениям, платежам и другим данным, которые ему не нужны для работы.

Где хранятся данные

Пробежки, настройки и игровая статистика хранятся на устройстве пользователя, в локальном хранилище мини-приложения. Пробежки и план подготовки дополнительно синхронизируются через серверное хранилище ВКонтакте (VK Storage) — по умолчанию синхронизация включена, чтобы история пережила очистку кэша и была доступна на другом устройстве. В облако уходят итоги тренировки и упрощённый маршрут, а не полный трек с тысячами точек.

В облаке также лежит план: цель, дата, ответы онбординга и отметки о тренировках. Облачные копии можно удалить кнопкой «Удалить все данные» — она очищает и устройство, и хранилище ВКонтакте.

Если очистить кэш приложения или удалить его, локальные настройки и игровая статистика исчезнут. Резервные копии тренировок и план восстановятся из VK Storage; для полной страховки в разделе «Данные и конфиденциальность» есть резервная копия JSON — её пользователь скачивает сам и сам решает, где хранить.

Обезличенная статистика

Приложение отправляет обезличенные события использования (открытие приложения, шаги онбординга программы, создание плана, отметка тренировки) через VK Bridge в статистику ВКонтакте. Эти данные нужны, чтобы понимать, какие шаги вызывают затруднения, и улучшать приложение. Они не содержат текста сообщений, координат и иных чувствительных данных.

Геолокация

Доступ к геолокации нужен только для записи маршрута пробежки. Сейчас функция записи временно отключена, и разрешение не запрашивается. Когда она включена, координаты используются исключительно для построения маршрута на устройстве.

В карточке пробежки можно скрыть первые и последние 200 метров маршрута, чтобы не показывать место старта и финиша рядом с домом.

Реклама

Приложение показывает рекламу через рекламную сеть ВКонтакте. Показ, таргетинг и обработка данных для рекламы регулируются политикой конфиденциальности ВКонтакте. Приложение не получает и не хранит персональные данные, собранные рекламной сетью.

Реклама не показывается во время записи пробежки, а частота показов ограничена, чтобы не мешать работе с приложением.

Клубный пробег

В клубную статистику передаётся только суммарный километраж за месяц по импортированным тренировкам. Идентификатор пользователя хранится на сервере в виде необратимого хеша: маршруты, имена, даты и отдельные тренировки не передаются. Наружу показываются только общие суммы — километры клуба за месяц и число участников.

Для хранения агрегатов используется облачная инфраструктура Yandex Cloud. Клубные суммы видны всем пользователям приложения, личные результаты — никому.

Передача данных третьим лицам

Приложение не продаёт пользовательские данные третьим лицам. Платформа ВКонтакте обрабатывает данные в рамках собственных правил, когда пользователь открывает мини-приложение, и предоставляет хранилище для синхронизации плана и резервных копий тренировок.

Права пользователя

  • скачать копию своих данных в формате JSON;
  • восстановить данные из ранее скачанной копии;
  • удалить все данные приложения с устройства одной кнопкой;
  • очистить журнал ошибок, который приложение ведёт локально для диагностики.

Всё это доступно в разделе «Данные и конфиденциальность» внутри приложения. Для полного удаления используйте кнопку «Удалить все данные»: она очищает и устройство, и облачные копии в VK Storage. Очистка кэша средствами ВКонтакте удалит только локальные данные, резервные копии тренировок и план при этом останутся в VK Storage.

Несовершеннолетние

Приложение не предназначено специально для детей и не собирает данные о возрасте. Тренировочные рекомендации носят справочный характер и не заменяют консультацию врача.

Изменения политики

Если правила обработки данных изменятся, обновлённая редакция появится по этому же адресу с новой датой. Продолжая пользоваться приложением после изменений, пользователь принимает новую редакцию.
